      Step 02 · 頻道定位

      你的頻道要講什麼？

      主題完全由你決定，不限財經。沒有想法的話，先從下面的範例挑一個改。

      AI 寫稿時會用這個名字自稱（例如開場「歡迎來到貓奴研究所」）。不一定要跟 YouTube 上的頻道名稱一樣，之後隨時可以回來改。
      這是 AI 判斷「什麼題目適合這個頻道」的依據。範圍太大（例如「生活」）AI 會亂跳題；太窄則很快就沒題目可做。一句話講清楚「幫誰解決什麼」最好。
      寫得越具體，AI 選的題目越貼近真實搜尋。
      點上面的選項會把描述填進框裡，你也可以直接改字。AI 寫的每一句旁白都會照這段描述的口吻。

      Step 03 · 內容方向

      給 AI 一些選題方向

      AI 會參考這些方向，想出觀眾會主動搜尋的題目，而且不會重複已經做過的。

      種子主題是 AI 選題的出發點，不是最終題目。寫你頻道常講的幾類內容，AI 會從這些方向延伸出具體題目。3～5 個就夠。
      只影響長片；短片固定約 50 秒。

      可以引用的數字

      為了防止 AI 編造數據，腳本裡出現的每一個數字都必須先登記在這裡，而且要跟它所屬的主體寫在同一句，否則整支片會被擋下。不打算講數字就全部留空，AI 會被要求全文不寫數字。

      ① AI 寫稿 · OpenRouter 未設定

      OpenRouter 是一個「AI 總機」：一個帳號、一次儲值，就能用 OpenAI、Google、Anthropic 等各家的 AI。這個工具靠它來選題和寫腳本。「API 金鑰」就是讓這個工具用你的帳號付費的密碼。

      1. 註冊：打開 openrouter.ai，右上角 Sign in，用 Google 帳號登入最快。
      2. 儲值：到 Credits 頁 按 Add Credits，用信用卡儲值。先儲最低金額就夠試很多支片，下面選模型時會顯示每支片大約花多少。
      3. 建立金鑰：到 Keys 頁 按 Create Key，名稱隨便取（例如 youtube）。建好會出現一串 sk-or- 開頭的字，只會顯示這一次，馬上按複製。
      4. 貼到下面，按「測試金鑰」。看到綠色的「金鑰有效」就成功了。
      已經設定過的話留空即可，舊的不會被清掉。
      下面先列主要廠商的模型，新的排前面；想找其他模型請用搜尋。價格是粗估。

      ③ 自動上傳到 YouTube 未設定

      想讓這個工具幫你上傳，要先向 Google 申請一張「通行證」，也就是一個 JSON 檔，讓它能代表你的帳號上傳影片。申請免費，只是步驟多。也可以完全跳過：用「產片」做好後，自己到 YouTube 手動上傳一樣可以。
      自動上傳的片一律是「私人」，你看過沒問題再自己改成公開。

      一步步教你申請（約 15 分鐘，只要做一次）
      1. 建立專案：打開 Google Cloud 建立專案，用你頻道的那個 Google 帳號登入。專案名稱隨便取（例如 my-channel），按「建立」。第一次用會先要你同意服務條款。
      2. 開啟 YouTube 功能：確認左上角選的是剛建的專案，在最上面的搜尋列輸入 YouTube Data API v3，點進去按「啟用」。再搜尋 YouTube Analytics API，一樣按「啟用」。
      3. 設定同意畫面：搜尋列輸入 OAuth 同意畫面（或 OAuth consent screen）點進去，按「開始」。應用程式名稱隨便填，電子郵件選你自己；「目標對象」選外部，其他照預設一路按下一步到完成。
      4. 把自己加成測試使用者：在同一區找到「目標對象」（Audience），在「測試使用者」按「新增使用者」，填你頻道的 Gmail，儲存。這步漏掉的話，之後登入會被拒絕。
      5. 建立用戶端：到「用戶端」（Clients），或舊版介面的「憑證 → 建立憑證 → OAuth 用戶端 ID」。應用程式類型選 電腦版應用程式（Desktop app），名稱隨便填，按「建立」。
      6. 下載 JSON：建好後按「下載 JSON」，會得到一個 client_secret_….json 檔，拖到下面的框裡。
      7. 第一次上傳時：瀏覽器會跳出 Google 登入頁，選你的頻道帳號。會看到「Google 尚未驗證這個應用程式」，這是正常的，因為這個應用程式就是你自己剛建的：按「繼續」（或「進階 → 前往…」），再勾選允許。

      常見問題：同意畫面是「測試中」狀態時，Google 的授權大約 7 天會過期，到時候上傳會再請你登入一次，照做就好。

      把下載的 JSON 檔拖到這裡
      或點一下選擇檔案
      填了的話，上傳的片會自動加進這個播放清單。取得方式：在 YouTube 打開你的播放清單，網址裡 list= 後面那一串（通常 PL 開頭）就是。
      Step 05 · 產片

      做出第一支影片

      建議先「試跑」一次，確認流程沒問題再正式產片。

      三個按鈕差在哪？

      從左到右，一個比一個「真」：

      試跑
      用內建假稿子、假配音走完整個流程，做出一支範例片
      免費
      不用任何金鑰，確認電腦環境沒問題
      產片
      AI 真的選題、寫稿、配音、剪片，影片存在你的電腦
      OpenRouter 扣一點錢
      金額見第 4 步模型旁的估價
      需要第 4 步的 OpenRouter 金鑰
      產片並上傳
      做完直接傳到你的 YouTube 頻道，以「私人影片」上傳，只有你看得到
      同上
      上傳本身免費
      還需要第 4 步的 Google 授權
      已經想好要講什麼就直接打，例如「貓咪為什麼半夜暴衝」。留空的話，AI 會從你的種子主題延伸出一個題目，也會避開已經做過的。
      長片是一般橫式影片，長度照第 3 步的設定，會自動做縮圖。短片是手機直式的 YouTube Shorts，約 50 秒，標題會自動加上 #Shorts；YouTube 規定 Shorts 不能超過 3 分鐘，超過的話會擋下、不上傳。

      做完之後

      • 畫面會出現影片預覽，檔案存在程式資料夾裡的 output 資料夾，每支片一個子資料夾（裡面有影片、旁白稿、配音）。
      • 第一次按「產片並上傳」時，會跳出 Google 登入頁：選你的頻道帳號並按允許。之後就不用再登入（測試模式下大約 7 天要重登一次）。
      • 上傳的片是私人影片，不會直接公開。到 YouTube 工作室 →「內容」找到它，先自己看一遍，確認沒問題再把「瀏覽權限」改成公開。
